# 도달범위 · 윤곽 측정 기록 (작업 9, 2026-10-10)

> 이 문서는 `.cache/waam/analysis/REPORT.md`(작업 9 산출물)의 값을 옮겨 보존한 것이다. 원본은 gitignore(`.gitignore:5`)라 커밋되지 않는다. **작업 10에서 분석을 다시 돌리지 않았다** — 아래 숫자는 REPORT.md에 적힌 값 그대로다.
> 구분: **측정** = REPORT.md에 적힌 Validator 함수 결과 / **가설** = 측정되지 않은 추정 / **미측정** = 측정한 적 없음.

## 1. 측정 방법 (측정)

- 모든 값은 Validator 함수 `load_config`, `load_target_mesh`, `slice_target_layers`의 결과다. 우리 `slicing` 구현이 아니다.
- 입력: `WAAM_Validator/tests/NN/{config.yaml, target.stl}`을 읽기만 했다(수정 없음). 결과는 스크립트 옆에만 썼다.
- 판정 기준은 **단면 폴리곤**이다. 비드 중심선(실제 TCP 경로)이 아니다. 가장자리에서 약 4 mm(비드폭/2)의 차이가 있을 수 있다 — **영향은 미분석**.
- 로봇 도달 원판: `xy_reach_radius_mm` = 1500, 로봇 base 3개. 원판은 **4096각형 내접 근사**(면적 오차 약 4e-7 상대, 경계 면적에 한정).
- 면적 비율은 층 면적 가중이다. "몇 대가 닿는가"는 포함-배제로 계산했고, 음수 잔차는 0으로 잘랐다(수치 잡음 열).
- "1대로 전부 도달": 가장 먼 단면 꼭짓점까지의 XY 거리 ≤ 1500. 원판이 볼록하므로 외곽 꼭짓점 검사가 정확하다.
- 윤곽 수 = 폴리곤 수(외곽) + 홀 수 (닫힌 루프).
