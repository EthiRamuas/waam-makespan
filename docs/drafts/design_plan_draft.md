## 1. 우선순위 출발점 검토

제시안: 1 PASS → 2 비공개 일반화 → 3 makespan/ratio → 4 계산 시간 → 5 구현 위험·3단계 근접성.

지적 (모두 의견, 판단은 사람):
1. **자체 부과 제약(국소 선후관계·아크 시간, CLAUDE.md)은 순위가 아니라 제약**으로 두는 것이 맞다. 우선순위 표에 없으면 3순위(makespan)와 거래되는 것처럼 읽힌다. H7(속도 허용폭)도 같은 범주 후보.
2. **1과 2는 사실상 같은 축**이다. 비공개 모델에서 Validator 미통과 = Fail이므로 "일반화"의 핵심은 *처음 보는 형상에서의 PASS 여유*다. 공개 6개 PASS 여유(IoU 마진, 충돌 마진)를 2순위의 측정 대리 지표로 쓸 수 있다.
3. **3과 4의 상대 가중은 미확인**이다(평가 = makespan + 계산 시간 + 일반화, 결합 방식은 강의자료에서 확인 필요). 구성적 휴리스틱의 계산 시간이 작을 것이라는 것은 가설.
4. **5는 평가 축이 아니라 동률 깨기**다. 중간평가(10/20)는 진행 상황만 본다(C-23) → 3단계 근접성은 점수가 아니라 일정 위험.
