## 중단 조건

다음 중 하나라도 일어나면 현재 항목을 멈추고 아래 "중단 시 수습"을 한다. 1~3번은 의존 없는 항목이 남아 있어도 **세션 전체를 종료**하고, 4~7번은 해당 항목만 멈추고 의존 없는 다음 항목을 계속한다.
1. 같은 오류로 2회 연속 실패 *(세션 종료)*
2. 리뷰 반영 후 기존 pytest 실패 *(세션 종료)*
3. 종료 한도(03:00) 도달 또는 항목별 타임박스 2배 초과(N1 300분, N2 60분, N3 80분) *(세션 종료)*
4. 명세 밖 결정 필요 *(해당 항목 보류)*
5. 금지 행위가 필요해 보임 *(해당 항목 보류)*
6. N1 #13 폴백 후 실패, 또는 #1·#2·#5 가설값 미달 *(N1 미합격, N3 미착수, N2는 계속)*
7. N2 판정 불일치 *(결과 기록 후 테스트 stash, 가드는 그대로)*
8. 토큰 95% — 측정 방법 **미확인**. 적용하지 않고 시작·종료마다 커밋해 간격을 줄인다.

### 중단 시 수습

1. 미완성 코드가 있으면 `git stash push -u -m "night-2026-10-10b Nn 중단: <사유 한 줄>"`로 치운다. 이후 `git status --short`가 비어 있어야 한다.
2. **`git stash`가 권한 거부 등으로 실패하면 다른 수습(커밋, checkout, reset, 파일 삭제 등)을 시도하지 말고 즉시 멈춘다.** 트리가 더러워도 그대로 두고 아침에 사람이 판단한다. 이 경우 PROGRESS.md도 더 쓰지 않는다.
3. stash가 성공했으면 `PROGRESS.md`에 원인, 실패 수치, 현재 상태, stash 메시지를 적고 그 기록만 커밋한다. 마지막 커밋 = 마지막으로 테스트가 통과한 코드 + 기록이어야 한다.
4. 사용량 한도로 세션이 멈추면 이 수습을 할 수 없다(편집 도중 정지 가능). 아침 복귀 체크리스트 1번이 이를 다룬다.
